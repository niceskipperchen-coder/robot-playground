# Contributing

Please open an issue with the challenge, RobotScript program, expected result, and observed result. A share link is useful; do not include private information in public reports.

For code changes, run `npm ci`, `npm test`, and `npm run build`. Add a regression test for parser, simulation, or sharing behavior. Keep source parsing bounded; do not replace the interpreter with eval or arbitrary JavaScript execution.

When changing the interface, check one complete challenge, pause/step/reset, an imported share link, and a narrow viewport. Document any change to the educational physics assumptions.
